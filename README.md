# DashboardAPI-EC

Servicio web para descubrir y visualizar entornos HPE Aruba Networking EdgeConnect a través de sus APIs.

La versión actual es **1.0 stable**, soportada exclusivamente en Ubuntu y distribuida como paquete `.deb`.

## Instalación rápida en Ubuntu 24.04

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/Ryuz-crypto/APIIntegration.git
cd APIIntegration/DashboardAPI-EC
sudo ./scripts/install-ubuntu.sh
```

La documentación de arquitectura, operación, autenticación, Swagger 9.6 y desarrollo se encuentra en [DashboardAPI-EC/README.md](DashboardAPI-EC/README.md). La guía detallada de instalación y primer uso está en [DashboardAPI-EC/docs/INSTALLATION.md](DashboardAPI-EC/docs/INSTALLATION.md).
