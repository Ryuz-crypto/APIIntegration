# DashboardAPI-EC

Servicio web para descubrir y visualizar entornos HPE Aruba Networking EdgeConnect a través de sus APIs.

La versión actual es **1.0 stable**, soportada exclusivamente en Ubuntu y distribuida como paquete `.deb`.

La documentación de arquitectura, instalación, operación, autenticación, Swagger 9.6 y desarrollo se encuentra en [DashboardAPI-EC/README.md](DashboardAPI-EC/README.md).
